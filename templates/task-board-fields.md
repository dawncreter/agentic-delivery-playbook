# Task board fields an agent needs

| Field | Why the agent needs it |
|---|---|
| Owner | To route updates and nudges |
| Status | To report progress automatically |
| Due date | To flag slippage early |
| Dependencies | To spot blockers before they hit |
| Source link | To trace every task to a meeting, ticket or decision |
| Last update | To detect stale work |
| Risk level | To prioritize what reaches leadership |
