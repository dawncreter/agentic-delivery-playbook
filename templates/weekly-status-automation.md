# Weekly status automation

| Step | Trigger | Action | Owner |
|---|---|---|---|
| 1 | Daily | Pull task changes from the board (Jira/Linear/ServiceNow) | Automation |
| 2 | After each meeting | Run meeting capture; add actions to the board | Automation |
| 3 | Friday 2pm | Agent drafts status: progress, risks, decisions, next week | Agent |
| 4 | Friday 3pm | Delivery lead reviews and edits (10 minutes) | Human owner |
| 5 | Friday 4pm | Send to stakeholders; archive in the knowledge base | Automation |

Measure: hours spent on status before vs. after, cycle time, and stakeholder satisfaction.
